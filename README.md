# Tabla Notation Tool

## Key Features

**Tala Selection System**: The tool supports six major talas with their Devanagari names:

- तीनताल (Teentaal) - 16 beats
- झपताल (Jhaptaal) - 10 beats
- एकताल (Ektaal) - 12 beats
- रूपक (Rupak) - 7 beats
- दादरा (Dadra) - 6 beats
- कहरवा (Keherwa) - 8 beats

**Matra Division**: Each matra (beat) is divided into 8 laghus as requested, creating a precise grid system for composition.

**Virtual Keyboard**: The app features a comprehensive keyboard with categorized bols:

- **Daya (Right Hand)**: ता, ना, तिन, तू, ते, तेटे
- **Baya (Left Hand)**: क, के, कत, ग, गे, घे
- **Compound**: धा, धिन, धागे, धिनागिना, तिरकिट, किटतक

**Composition Grid**: Interactive grid where you can place bols in specific laghu positions, with visual indicators for sam (X), tali (2,3), and khali (0).

**Educational Features**:

- Display of theka (basic pattern) for each tala
- Bol pronunciation guides with romanized equivalents
- Visual vibhag separation and beat numbering

**Composition Management**:

- Save/load compositions using browser storage
- Export functionality to text format
- Clear composition option
- Show theka reference

**Playback System**: Basic playback simulation with tempo control and visual position tracking.

The application uses authentic Devanagari script throughout and follows traditional tabla notation principles. The interface is designed to be intuitive for both students and teachers, making it easy to create, edit, and practice tabla compositions with proper notation.

The tool provides a modern digital solution for tabla notation while preserving the traditional aspects of the art form, including proper vibhag structure, tali-khali patterns, and authentic bol representation in Devanagari script.
